| B-002 | Capability | No *account* remote-provider API key is configured (local Ollama runs end-to-end). | Registry/router + presets are implemented, tested and network-reachable. | B-003 | Platform | Wayland/portal (D3) cannot be exercised here: this is an X11 session and `xdg-desktop-portal` is absent. | The portal capture path + detection are implemented and unit-tested with fakes; produce live evidence on a Wayland host with a portal. | OPEN |
| B-004 | Scope | Full frontier computer-use (OCR/CV, browser control, delegation, packaging) exceeds one checkpoint. | Deliver verified vertical slices; keep requirements explicit; never claim completion prematurely. | OPEN |

| B-006 | Safety | Any future enabling of real input risks unintended clicks/typing. | Emergency stop, pause, takeover, and safe input release implemented; keep `BLAXCY_ENABLE_REAL_INPUT` unset by default. | OPEN |
| B-007 | Performance | On a loaded host (observed load avg ~9) the local `tinyllama` model is slow enough that `blaxcy delegate` can exceed 2 minutes per call; the 60 s per-provider timeout makes this honest but sluggish. | Not a defect. Mitigations if desired: prefer a smaller local model for delegation, lower `Router.timeout_s`, or configure a faster remote provider (partly blocked on B-002). | OPEN |
| B-008 | Scope (decision, not a defect) | Not every component is process-isolated: **Tools** (terminal/filesystem/browser/delegation) intentionally stay in-process. | Rationale in DEC-023: tools are thin `Action` builders; Policy + Body is the single security chokepoint and `panic_release` is bound to the local session, so isolating tools would weaken (not strengthen) the model with no performance win. Browser CDP and delegation model calls are already isolated/remote. | CLOSED (decided) |
| B-009 | Scope | The authenticated IPC is a **local Unix domain socket only** (no network transport), which matches the single-host desktop use case. | Documented deliberately; a remote transport would need its own TLS/authorization design and is out of scope. | OPEN (by design) |
| B-010 | Evidence integrity | The B7 evidence artifact (`B7_EVIDENCE.md`) was clobbered by an **unauthorized** `accept-live` run. A genuine artifact still requires `BLAXCY_ENABLE_REAL_INPUT=1 blaxcy accept-live`. Until then B7 stays `IMPLEMENTED`, not `VERIFIED`. | OPEN |
